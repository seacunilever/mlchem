mlchem.chem.visualise.space module
----------------------------------

Independent visual encodings
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

After ``ChemicalSpace.prepare()``, each visual property can use any prepared
dataframe column independently. Extra columns in the original input are aligned
by SMILES and retained. For example, with the corresponding class, dataset, and
score categories present:

.. code-block:: python

   space.plot(
       colour_by='CLASS',
       colour_map={'score[0]': 'navy', 'score[1]': 'orange'},
       shape_by='METADATA',
       shape_map={'train': 'circle', 'test': 'triangle'},
       opacity_by='METADATA',
       opacity_map={'train': 0.4, 'test': 0.9},
       marker_size_by='SCORE',
       marker_size_map={0.1: 7, 0.9: 14},
       save_html=True,
       filename='chemical_space',
   )

For continuous numeric colour with a labelled colour bar:

.. code-block:: python

   space.plot(
       colour_by='SCORE',
       colour_continuous=True,
       colour_palette=['navy', 'cyan', 'gold'],
       shape_by='METADATA',
       shape_map={'train': 'circle', 'test': 'triangle'},
   )

Every observed categorical value must be mapped; extra mapping keys are allowed.
Unknown columns, missing values, invalid Bokeh colours/shapes, non-finite values,
opacities outside [0, 1], and nonpositive sizes raise errors. Numeric colours are
categorical unless ``colour_continuous=True``. The continuous palette defaults
to Viridis256.

Each ``*_by`` conflicts only with the corresponding legacy ``*_list``.
Continuous colour also conflicts with ``colour_map``. Unspecified encodings
keep their legacy defaults: colour, opacity, and size by CLASS; shapes by
METADATA when both metadata flags are enabled. Scalar ``marker_size`` is
overridden by a size list or map. The classic 866 by 650 pixel plot, hover
details, tables, notebook display, and HTML export remain available.
Categorical legend keys name the encoding and column and use one actual glyph
sample, avoiding overlaid shape samples. Opacity keys state alpha and size
keys state the mapped pixel size: Bokeh normalises legend glyph dimensions,
so size swatches are not to scale. Zero opacity is intentionally transparent.
The ``metadata_exists`` and ``metadata_categorical`` constructor options are
legacy controls for the special ``METADATA`` column and its default shape
behavior. They are not required for other extra columns or explicit ``*_by``
encodings; ``shape_by`` works with any prepared column without those flags.

Structure paths
~~~~~~~~~~~~~~~

Safe, unambiguous CLASS labels can be used directly as folder names. Labels with
spaces/punctuation, Windows-reserved names, and case-insensitive collisions are
encoded with a stable digest for portability and collision safety. Display
labels are unchanged. Inspect ``space.class_structure_folders`` and use the
``MOLFILE`` column generated by ``prepare()`` rather than reconstructing paths
from labels.
